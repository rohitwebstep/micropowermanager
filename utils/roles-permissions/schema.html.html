System Roles & Permissions

Complete documentation of access levels, roles hierarchy, and domain-level permissions based on the application rules.

Roles Hierarchy

Owner

Level 1

Full control over the entire system. Can manage all accounts including creating/removing administrators. Cannot delete other owners.

Access: All Permissions

Admin

Level 2

Manage all system data and settings. Can manage admin accounts and lower levels, but NOT owner accounts.

Restriction: No Owner Management

Financial Manager

Level 3

Manage customers + financial/transaction data. Cannot change system settings or manage users.

Focus: Finance & Customers

User

Level 4

Manage customers and related data only. Cannot access financial information, transactions, or system administration.

Focus: Customer Data Only
